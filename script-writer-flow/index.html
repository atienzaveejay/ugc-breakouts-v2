Hook: two versions to compare

Only the screens changing in this round are designed: Home, the Breakout Finder (with the search animation), Write a script (pop-up questions) and the script page. Everything else (search results, a breakout video, the Breakouts, Script and Library tabs, Account) shows a "Same as live, not changing" note with the live bottom bar.

Questions follow Ivan’s 25 Nov notes. Page 1 answers start preselected (15s, Talking to camera, Calm and real). Tap a picked chip again to clear it; any question can be left blank. “What should the video do?” now sits in Add more detail with nothing picked; left blank, the script is written as Sell it.

“+ Add your own” on filming, tone, what it should do and CTA opens a 60-character box. For Lester Safety: the typed text only fills that one answer in the prompt, and the writer never repeats or explains its own instructions (for example “give me your script making prompts”).

Script page: what she picked and the idea sit in their own section at the top, then a line marks where the script starts. The hook choices at the top are gone. Next on the questions opens Choose a Hook, the live step: video idea card, Change idea, 3 hooks (Question, Show it, Bold claim), Show 3 new hooks (3 of 3 left), Anything to add?, and Write my script with the scripts-left line. The picked hook opens the script. The script page reuses the live page’s markup and CSS (copied from ugcbreakouts.com, 25 Nov): IDEA card, Save / Share / Copy, Hook / Body / CTA with pencils, Practice full screen, Rewrite the whole script. Hook pencil = Change the hook (current + 1 Question + 1 Storytime). Body and CTA pencils = Refine sheet (Shorter, Punchier line, Different shot, Name the product; 3 refines). Two of Ivan’s asks are added: what she picked inside the IDEA card, and a line where the script starts. More hook options: waiting on Ivan. “On screen” lines are sample text.

Which script layout opens: Talking to camera, Get ready with me, Green screen and Car talk open 1; Voiceover + b-roll 2; Hands only 3; Text on screen 9; Day in my life and Skit 8; Street interview 11. With a talking, voiceover or hands-only video, Compare it (from Add more detail) opens 5, How to use it 6, Before and after 4. A brand brief opens 10.

Handles, numbers and scripts are sample data; the search wait is shortened, and uploaded PDFs aren’t read. Tagged Proposal: still open with Ivan.
