Script Writer v4: start from your own idea

From the call with Ivan on 10 Nov (to-dos 6 and 8). The Idea Generator is gone. The creator types a product or topic first, swipes through 10 video ideas built on formats for that keyword, picks one, chooses a hook, then gets the script. Brief Buddy and starting from a breakout stay as second options.

The script page gets 3 new layouts so the lines she says on camera are the easiest thing to read. All sample data comes from UB 3.1 (lip oil, @maya.creates).

The flow

  1. Type a product or topic. One box, chips from her TikTok to fill it.
  2. Finding ideas. The shared processing screen from Magic moments v2.
  3. 10 ideas, swipe left and right. Each one is a format applied to her keyword, with a sample hook.
  4. Choose a hook. Same as 3.1, with the picked idea shrunk to one line on top.
  5. Writing your script. Same processing screen.
  6. Your script in layout A, B or C (switch above).

Script layouts: 3 ways to read the same script

Ivan on the current script page: it doesn’t call out, and the font sizes, bolding and format are hard to read. In 3.1 every part is a teal box with 4 labels of the same size (Direction, Say, Visuals, Text on screen), so the line she says competes with everything around it. Each layout below is built for one job.

What changed vs 3.1

  • Idea Generator removedIt was slow and its ideas came straight from the format database, so many had nothing to do with the creator. The card on the Script start screen is gone.
  • “My own idea” is now the main entryIn 3.1 it was a collapsed second card that went straight to hooks. Now it is the first thing on the page and leads to 10 ideas for that keyword.
  • Swiping browses instead of deciding3.1: swipe right to use, left to skip, one card at a time. v4: swipe either way to move through all 10, dots show where you are, one button picks the idea on screen. You can go back to an idea you passed.
  • Hook screen: picked idea shrinks to one lineThe big selected card in 3.1 pushed the hooks below the fold. Now the hooks start in the top half.
  • Processing screens use the Magic moments v2 styleOne line, a 3-part bar, 3 steps that tick, one panel. Replaces the bowl animation on Writing your script.
  • Script page: 3 layouts instead of teal boxesThe line she says is the biggest text on the page in every layout. Refine, Change, rewrites, Save, Share and Copy work the same as 3.1.
